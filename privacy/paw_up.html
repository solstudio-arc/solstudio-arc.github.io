꾹 업

개인정보처리방침

꾹 업은 다양한 클릭 미션을 통해 기상을 돕는 모닝콜 앱이며, 알람 동작과 API 통신에 필요한 최소한의 권한만 사용합니다.

회원가입 없음 광고 없음 알림 권한 요청 인터넷 권한 사용
01

개요

본 앱(꾹 업)은 사용자의 개인정보 보호를 중요하게 생각하며, 「개인정보 보호법」 등 관련 법령을 준수합니다.

본 앱은 별도의 회원가입 또는 로그인 기능을 제공하지 않으며, 사용자를 식별하기 위한 계정 정보를 수집하지 않습니다.

02

기기에 저장되는 정보

본 앱은 알람 및 클릭 미션 기능 제공을 위해 다음 정보를 기기에 저장할 수 있습니다.

  • 알람 시간 및 반복 설정
  • 알림, 소리, 진동 관련 설정
  • 클릭 미션 방식 및 클릭 횟수 설정
  • 앱 테마 및 화면 관련 설정

위 정보는 앱 기능 제공을 위해 기기에 저장되며, 별도 계정 정보와 연결되지 않습니다.

03

사용자에게 직접 요청하는 권한

본 앱은 알람 및 모닝콜 기능 제공을 위해 다음 권한을 사용자에게 직접 요청할 수 있습니다.

권한 사용 목적 거부 시
알림(POST_NOTIFICATIONS) 설정한 알람, 모닝콜, 클릭 미션 진행 및 종료 알림 제공 알림을 통한 알람 안내 기능을 사용할 수 없습니다.
04

기능 동작을 위한 권한

다음 권한은 별도 동의창 없이 앱 기능 동작을 위해 사용될 수 있습니다.

  • 진동(VIBRATE): 알람 및 클릭 미션 진행 중 진동 피드백 제공
  • 인터넷(INTERNET): API 사용을 위한 네트워크 통신
  • 네트워크 상태 확인(ACCESS_NETWORK_STATE): API 통신 가능 여부 및 네트워크 상태 확인
05

API 및 네트워크 통신

본 앱은 앱 기능 제공을 위해 외부 API와 통신할 수 있으며, 이를 위해 인터넷 권한을 사용합니다.

API 통신 과정에서 기기 네트워크 연결 상태 등 서비스 제공에 필요한 기술적 정보가 처리될 수 있습니다.

본 앱은 별도의 로그인 기능을 제공하지 않으며, API 통신을 위해 사용자의 계정 정보를 수집하지 않습니다.

06

광고 및 제3자 광고 서비스

본 앱은 현재 광고를 제공하지 않으며, Google AdMob 등 광고 SDK를 사용하지 않습니다.

광고 제공을 위한 광고 ID 또는 맞춤형 광고 관련 정보는 본 앱에서 처리하지 않습니다.

07

사용하지 않는 권한

본 앱은 다음 권한을 사용하지 않습니다.

  • 위치, 카메라, 마이크, 연락처
  • 전화, 문자, 블루투스, 캘린더
  • 건강정보, 사진·동영상 및 전체 저장소 권한
08

개인정보 보관 및 관리

본 앱은 별도의 계정 또는 자체 서버를 통해 사용자의 개인정보를 저장하지 않습니다.

기기에 저장된 알람 및 미션 설정 정보는 앱 삭제 시 함께 삭제됩니다.

09

제3자 제공

본 앱은 사용자의 개인정보를 제3자에게 판매하거나 제공하지 않습니다.

본 정책은 서비스 업데이트에 따라 변경될 수 있습니다.
